# Project context and decisions

The user first asked whether the supplied DOS game archive could become a genuine
native Apple Silicon macOS app without a DOS emulator. Inspection established a
16-bit x86 DOS program and compiled graphics resources. Original build source was
not supplied. Direct source recompilation, static binary translation and native
reimplementation were assessed as separate approaches.

The user chose the native prototype, then authorized the complete native
reimplementation as an ongoing goal. The prototype's invented rules were replaced
with behavior recovered from original code and data. The final app uses native
Swift/Cocoa logic and translated data; it does not execute DOS code.

Original inputs remain read-only. The supplied local OutNumbered Gameplay.mkv
replaced the YouTube link as the gameplay and sound reference. Screenshots from
https://www.myabandonware.com/game/super-solvers-outnumbered-115 were also supplied
as visual reference. No subsequent YouTube reference is needed. The source ZIP
SHA256 is 6766fbaa4152436ec1096bf1a06c5889a7b82f25b5ee33bb7583629b8252dd14;
the local MKV SHA256 is 6960fb011e044a141e75e734e35140ff5c6c62e8e3440bf78f96d27baf957205.
Neither original input nor player saves are published here.

Question data covers the recovered finite domain of 80 records, ten stored seeds
and four variations: 3,200 cases. This is ahead-of-time data translation.
Unusual original empty paragraphs were retained instead of inventing replacements.

The user authorized a private GitHub repository with the plan and project-focused
chat context. They later instructed that GitHub updates wait until the final app
was ready. Local milestones continued under that hold. The final 1.0 snapshot
consolidates those milestones after runtime, ordinary play, save and rebuild gates.
This is a project summary, not a verbatim conversation or internal tool transcript.

Evidence boundaries remain explicit: recovered code/data, automated native checks,
live UI observations, raster comparisons, audio measurements and package rebuilds
establish different facts. The final ordinary campaign used normal controls and
unmodified saves, without development checkpoints or reading hidden puzzle answers.
