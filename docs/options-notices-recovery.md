## Native integration

Options and notices own frozen backdrops and explicit modal depth. Local0.32 removes the Options backdrop before opening its child, matching the original menu callback sequence. An ordinary new-user message pauses/resumes only its own clock layer, acknowledges on dismissal, and saves its seen state. Nested settings guidance freezes its parent and dismisses back to that editor. Practice guidance changes only its separate state and never writes the suspended adventure. Test-only injected message presenters preserve synchronous state checks; production uses the new game-rendered panels. Parent commands cannot replace an active child. Closing flushes pending ordinary keys/held movement.

Mouse menu/button selection is a macOS adaptation. Message notices retain their source keyboard dismissal. Cross-menu keyboard navigation and toolbar File routing now follow the three original tabs. Remaining arbitrary DOS modifier/BIOS key combinations are not claimed equivalent. The native menu bar remains available as a platform adaptation.
