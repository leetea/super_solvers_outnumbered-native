# EGA palette recovery — milestone 0.28

The EGA display initialization at 104b:02c1 (loaded 0x10771) sets BIOS mode 0Dh, page zero, builds its scanline offsets and calls 104b:0298. That routine executes AX=1000h/BX=0001h/INT10h followed by AX=1000h/BX=0100h/INT10h. BIOS palette function 00h takes the register in BL and its value in BH: palette entry 1 becomes 0 (black), and entry 0 becomes 1 (blue). The successful raw instructions and source identity are retained in verification/palette-instructions-0.28.json. The earlier template-code-analysis/palette-driver-assembly.json is a masked-fill routine; it was not evidence of palette initialization.

For interpretation of the BIOS ABI, the primary implementation reference is DOSBox Staging's INT10 handler, lines138–147: https://github.com/dosbox-staging/dosbox-staging/blob/main/src/ints/int10.cpp . Its EGA palette register writer is https://github.com/dosbox-staging/dosbox-staging/blob/main/src/ints/int10_pal.cpp . These are documentation references only: no emulator is executed, linked, embedded or copied into the native app.

The character rasterizer at 104b:0516 reads DS:6b2a, configures EGA graphics-controller write mode2 and writes the color byte through glyph masks. The horizontal-span routine at 104b:0698 also uses mode2 and writes the supplied color directly. The palette therefore applies consistently to bitmap indices, text and primitive drawing. The native canvas now retains original bitmap indices rather than collapsing index1 into0. Color0 is blue, color1 opaque black, and the existing transparent sprite key0 still skips the destination pixel. Existing manually drawn black text/fills/outlines now use1; blue HUD backgrounds use0. Source pen11h for final prize prices is now retained as index1, and randomly selected price color0 remains blue rather than being mistaken for black.

This matters beyond appearance: XOR14 preserves the low plane. Original black1 becomes white15, while blue0 becomes yellow14. Collapsing black1 into0 before XOR produces the wrong effect and loses the source pixel identity. The native selection and television noise paths now operate on those retained indices. Timings, RNG and saved gameplay values are unchanged; activity plans are reconstructed and their color marks are transient.
